# Retired Luban-Lite board template

The maintained D213 application, board Kconfig, SCons composition and GUI/Headless defconfigs belong to [boa-z/luban-lite-carplay](https://github.com/boa-z/luban-lite-carplay/tree/carplay-oss/application/rt-thread/rtcarplay). The old copyable board template was removed to avoid duplicate SDK symbol definitions and stale platform ownership. Use the maintained host application rather than copying this directory. See [host migration](../../docs/luban-lite-migration.md) for paths, API compatibility and reproducible validation.
